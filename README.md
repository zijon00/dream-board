# ✨ 나의 생생한 꿈보드 (Dream Board Web App)

> **"상상할 수 있다면 이미 현실이 되기 시작한 것이다."**  
> 하고 싶은 것(Do), 갖고 싶은 것(Have), 해주고 싶은 것(Give)을 생생하게 기록하고, 내 사진·영상과 인터넷 검색, Gemini AI 합성 이미지를 결합해 매일 눈으로 확인하는 나만의 시각화 웹앱입니다.

---

## 🌟 주요 기능
1. **3대 소망 카테고리 분할 관리**:
   - 🏃 **하고 싶은 것 (DO)**: 경험, 여행, 버킷리스트, 취미
   - 💎 **갖고 싶은 것 (HAVE)**: 공간, 집, 자동차, 자산, 라이프스타일
   - 💝 **해주고 싶은 것 (GIVE)**: 부모님 효도, 가족 선물, 소중한 이들에게 베풀기
2. **3단계 스마트 미디어 매칭 파이프라인**:
   - **1순위 (내 사진/영상)**: 내 PC/스마트폰 사진 및 MP4 영상 직접 업로드 / 링크 첨부
   - **2순위 (인터넷 검색 - Zero-Config)**: 별도 API 키 없이 즉시 동작하는 고화질 사진 검색 및 로컬 자동 다운로드
   - **3순위 (Gemini AI 상상 및 합성)**: 구체적 묘사를 바탕으로 상상도 생성 및 내 얼굴/가족 사진을 꿈 장소와 합성
3. **📸 미디어 히스토리 영구 보존**:
   - 새로운 사진을 올리거나 AI 합성을 시도해도 이전 사진이 절대 지워지지 않고 카드 내 갤러리에 누적 보관
   - 썸네일 클릭 한 번으로 대표 사진 복구 및 교체
4. **🎬 시각화 명상 모드 (슬라이드쇼)**:
   - 전체 화면으로 꿈 카드들이 음악/문구와 함께 천천히 전환되는 명상 뷰어
5. **목표 관리 & 축하 효과**:
   - 목표 시기 및 확언(Affirmation) 입력, 꿈 달성 완료(✨) 체크 시 축하 꽃가루(Confetti) 효과

---

## 🚀 원클릭 실행 방법 (Windows)
1. 바탕화면 또는 이 폴더에서 **`run_dream_board.bat`** 파일을 더블클릭합니다.
2. 서버가 실행되고 기본 브라우저(`http://localhost:8000`)가 자동으로 열립니다.

## 📂 폴더 구조
```
dream-board/
├── backend/
│   ├── main.py          # FastAPI REST 엔드포인트 & 정적 파일 서빙
│   ├── models.py        # Pydantic 데이터 모델
│   ├── storage.py       # JSON 로컬 영구 보존 스토리지
│   ├── media_service.py # 파일 업로드 & 무설정 웹 미디어 검색
│   └── ai_service.py    # 최신 Gemini AI 상상도 생성 및 Vision 인물 합성
├── frontend/
│   ├── index.html       # 모던 반응형 꿈보드 UI
│   ├── app.js           # 핀터레스트 매거진 그리드, 미디어 모달, 슬라이드쇼
│   └── styles.css       # 감성 다크 테마 및 애니메이션
├── data/
│   ├── dreams.json      # 소망 데이터 영구 파일
│   └── uploads/         # 내 사진, 영상, AI 생성 이미지 원본 저장소
├── tests/               # Pytest 전체 단위/통합 테스트
├── run_dream_board.bat  # 윈도우 원클릭 자동 실행기
└── requirements.txt     # Python 의존성
```
