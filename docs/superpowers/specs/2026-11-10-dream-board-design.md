## 1. 기획 의도 및 배경 (Intent & Why)
소망(꿈)을 단순히 텍스트 목록으로만 적어두면 일상 속에서 쉽게 잊히고 감흥이 무뎌집니다. **하고 싶은 것(Do), 갖고 싶은 것(Have), 해주고 싶은 것(Give)** 세 가지 삶의 핵심 영역에 대해 구체적이고 생생한 묘사를 적고, 그에 딱 맞는 **내 사진·영상 → 인터넷 고화질 사진·영상 → AI 맞춤형 합성/생성 이미지**를 결합하여 매일 눈으로 보고 몰입할 수 있는 시각적 꿈보드(Vision Board)를 만듭니다.

우선은 복잡한 가입이나 외부 노출 없이 **나 혼자 매일 보며 영감을 얻는 개인용 시스템**으로 사용하고, 충분히 사용해 본 뒤 만족스러우면 가족이나 지인과도 시스템을 공유할 수 있도록 설계합니다.

## 2. 목표 및 비목표 (Goals, Non-Goals, Anti-Goals)

### Goals (핵심 목표)
1. **3대 카테고리 기반 생생한 꿈 기록**:
   - **하고 싶은 것 (Want to Do)**: 경험, 여행, 성취, 버킷리스트, 취미
   - **갖고 싶은 것 (Want to Have)**: 공간, 물건, 자산, 드림카, 라이프스타일
   - **해주고 싶은 것 (Want to Give)**: 부모님·가족·소중한 사람에게 베풀고 싶은 선물과 이벤트
2. **3단계 스마트 미디어 매칭 파이프라인**:
   - **1순위 (내 사진/영상 직접 등록)**: 내 PC/폰에 있는 사진이나 영상 파일을 드래그 앤 드롭으로 올리거나 직접 복사한 URL 첨부
   - **2순위 (인터넷 사진/영상 즉시 검색 - Zero-Config 무설정 기본)**: 별도 외부 API 키 설정 없이 앱을 켜자마자 바로 작동하는 공개 고화질 미디어 검색 탑재 (클릭 한 번으로 내 로컬 보관함에 영구 저장)
   - **3순위 (AI 이미지 생성 및 합성 - 요청 시)**: 원하는 사진이 없거나 내 얼굴/가족 사진을 꿈 장소와 합성하고 싶을 때 Gemini AI를 호출해 맞춤형 고화질 이미지 생성
3. **미디어 히스토리/갤러리 영구 보존**:
   - 사진을 새로 교체하거나 AI로 합성해도 **기존 사진이 절대 지워지지 않고 카드 내 갤러리에 누적 보존**되어 언제든 이전 사진으로 복원 가능
4. **일상 속 시각화 몰입 경험**:
   - 핀터레스트 스타일의 감성적인 **매거진 그리드 보드**와 **리스트 뷰** 전환
   - 선택한 꿈들을 배경음악/문구와 함께 전체 화면으로 감상하는 **‘시각화 슬라이드쇼(명상 모드)’**
   - 꿈 달성 여부(진행 중 / 달성 완료 ✨) 체크 및 달성일 기록

### Non-Goals (이번 버전에서 제외할 사항)
- 다중 사용자 회원가입, 로그인, 권한 관리, 소셜 피드 및 댓글 기능 (초기 버전은 1인 로컬 개인용에 집중)
- 무거운 외부 클라우드 DB(Firebase, Supabase 등) 필수 연동 (단, 데이터 레이어를 분리해 추후 쉽게 교체 가능하도록 설계)
- 복잡한 타임라인 기반 동영상 편집기

### Anti-Goals (절대 피해야 할 방향)
- 딱딱한 업무용 할 일 관리(To-Do List)나 엑셀 표처럼 건조한 화면이 되는 것 (볼 때마다 설레는 시각적 몰입감이 최우선)
- 사용자가 원하지도 않았는데 모든 항목마다 강제로 AI 이미지를 생성해 시간을 지연시키거나 기존 내 사진을 삭제/덮어쓰는 것

## 5. 사용자 확정 사양 (User-Decided Design)

### 5.1. 3대 카테고리 체계
모든 꿈 아이템은 아래 세 가지 카테고리 중 하나를 가지며, 상단 탭에서 전체 보기 또는 카테고리별 모아보기가 가능합니다.
- **하고 싶은 것 (`DO`)**: 예) "북유럽 오로라 아래에서 유리 이글루 숙박하기", "마라톤 풀코스 완주하기"
- **갖고 싶은 것 (`HAVE`)**: 예) "남산 뷰가 보이는 통창 서재가 있는 집", "포르쉐 911 카레라"
- **해주고 싶은 것 (`GIVE`)**: 예) "부모님 칠순에 비즈니스석으로 하와이 가족여행 보내드리기", "아내에게 작은 공방 차려주기"

### 5.2. 3단계 미디어 추가 워크플로우 (핵심 UX)
꿈 카드를 추가하거나 수정할 때 **[미디어 설정]** 영역에서 3가지 탭이 순서대로 제공됩니다:

1. **[탭 1: 내 사진/영상 (1순위 기본)]**
   - 내 컴퓨터/폰의 사진(`jpg, png, webp`)이나 짧은 영상(`mp4, webm`)을 드래그 앤 드롭으로 즉시 업로드
   - 또는 이미지 URL / 유튜브 영상 URL 붙여넣기
2. **[탭 2: 인터넷에서 찾기 (2순위 - 무설정 기본 탑재)]**
   - 외부 API 키 설정 없이 즉시 동작하는 공개 고화질 미디어 검색 엔진 탑재
   - 내가 입력한 꿈 제목/묘사를 바탕으로 추천 키워드가 자동 추출되어 고화질 사진을 즉시 검색 및 미리보기 제공
   - 클릭 한 번으로 내 로컬 저장소로 안전하게 다운로드되어 원본 보존
3. **[탭 3: AI로 상상/합성하기 (3순위 - 요청 시)]**
   - **모드 A (생생한 상상도 생성)**: 내가 적은 제목과 생생한 묘사를 바탕으로 Gemini AI를 호출하여 고화질 상상도 생성
   - **모드 B (내 사진과 꿈 장면 합성 - 2단계 스마트 파이프라인)**:
     - 내가 올린 인물/가족 사진의 시각적 특징(성별, 헤어, 의상, 분위기 등)을 Gemini Vision이 정밀 분석
     - 분석된 특징과 사용자가 요청한 꿈의 배경을 결합한 프롬프트를 생성하여, 내 얼굴/특징이 꿈의 장소에 자연스럽게 녹아든 고화질 합성 이미지 생성
4. **미디어 히스토리 관리 (보존 원칙)**:
   - 각 꿈 카드는 `media_history` 목록을 유지하여, 새로운 사진을 올리거나 AI 합성을 시도해도 이전 미디어가 사라지지 않음
   - 카드 상세에서 갤러리 썸네일 클릭 한 번으로 언제든 대표 사진을 교체하거나 이전 사진으로 복구 가능

## 6. 상세 화면 및 기능 설계 (Builder's Decisions)

*(아래 항목들은 사용성 극대화를 위해 기획자/개발자 판단으로 설계한 기본 사양이며, 언제든 수정 가능합니다.)*

### 6.1. 화면 레이아웃 (UI/UX)
```
+-----------------------------------------------------------------------+
| ✨ 나의 꿈보드 (My Vivid Dream Board)          [🎬 슬라이드쇼] [+ 꿈 추가] |
| "생생하게 꿈꾸면 현실이 됩니다"                 달성률: 3 / 15 (20%)    |
+-----------------------------------------------------------------------+
| [전체 (15)] [🏃 하고 싶은 것 (6)] [💎 갖고 싶은 것 (5)] [💝 해주고 싶은 것 (4)] |
| 필터: [전체 상태 ▾] [검색어 입력... 🔍]              뷰: [격자 ⊞ | 리스트 ☰] |
+-----------------------------------------------------------------------+
|  +--------------------+  +--------------------+  +--------------------+ |
|  | [사진 또는 자동재생 |  | [AI 합성 이미지]    |  | [고화질 영상 루프]  | |
|  |  짧은 영상 미리보기]|  | 💝 해주고 싶은 것   |  | 💎 갖고 싶은 것     | |
|  | 🏃 하고 싶은 것     |  |                    |  |                    | |
|  | "스위스 융프라우..."|  | "부모님 하와이..." |  | "통창이 있는 서재"  | |
|  | "눈 덮인 알프스를.."|  | "비즈니스석 타고.."|  | "아침 햇살 받으며.."| |
|  | 목표: 2027.05   [☆]|  | 목표: 2027.10  [✨]|  | 목표: 2028.03   [☆]| |
|  +--------------------+  +--------------------+  +--------------------+ |
+-----------------------------------------------------------------------+
```

1. **생생한 묘사(Vivid Description) 입력 가이드**:
   - 꿈을 등록할 때 단순 제목만 적지 않도록, **"그 꿈이 이루어진 순간, 눈앞에 무엇이 보이고 어떤 기분이 드나요?"**라는 감성 프롬프트 입력창과 목표 연도/시기(`target_date`), 다짐 한마디(`affirmation`) 입력란을 제공합니다.
2. **동영상 카드 자동 미리보기**:
   - 영상이 등록된 꿈 카드는 마우스를 올리거나 보드를 볼 때 소리 없이 부드럽게 자동 루프(Loop) 재생되어 생동감을 줍니다.
3. **시각화 슬라이드쇼 (명상/몰입 모드)**:
   - 상단 `[🎬 슬라이드쇼]` 버튼을 누르면 화면이 어두워지며 내 꿈 카드들이 전체 화면으로 한 장씩 천천히 전환됩니다. 내가 적은 생생한 묘사와 다짐 문구가 영화 자막처럼 함께 나타나 매일 아침/저녁 3분간 꿈을 시각화할 수 있습니다.
4. **추후 공유를 대비한 내보내기(Export) 기능**:
   - 내 꿈보드를 한 장의 고화질 이미지 포스터로 저장하거나 JSON 백업으로 내보낼 수 있는 기반을 마련합니다.

### 6.2. 기술 스택 및 아키텍처
- **Backend**: Python **FastAPI**
  - 기존 워크스페이스 환경(Python)과 완벽히 호환되며, `google-genai` 최신 SDK를 안정적으로 구동하고 로컬 파일 저장(`data/uploads/`)을 빠르게 처리합니다.
- **Frontend**: 모던 반응형 웹 UI (Tailwind CSS + Vanilla JS/HTML5 또는 경량 SPA 구조)
  - 별도의 복잡한 빌드 과정 없이도 즉각 실행되고, 다크/라이트 감성 테마와 부드러운 카드 애니메이션을 제공합니다.
- **원클릭 실행**: 바탕화면이나 폴더에서 `run_dream_board.bat`만 더블클릭하면 서버가 켜지고 브라우저가 자동으로 열리도록 구성합니다.
